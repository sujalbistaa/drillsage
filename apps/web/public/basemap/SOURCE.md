# Basemap tiles

`bm5-<x>-<y>.jpg`: Web Mercator zoom-5 tiles (x 15–17, y 8–10) of NASA's Blue Marble shaded
relief with bathymetry, from NASA GIBS (`BlueMarble_ShadedRelief_Bathymetry`, 2004-08-01).
NASA imagery is in the public domain. Credit: NASA Earth Observatory / NASA GIBS.

Shipped with the app so the locator map works offline. The field itself sits in open sea,
where no imagery provider has detail at field scale, so the field view stays a plan drawing.
